# How to paste this into Grok (Roger)

1. On your own computer, sign into https://grok.com with the account that owns srfp-media-kit.grok.me
2. Start a new Build / Apps chat
3. Open GROK_BUILD_PROMPT.md in this repo and copy **everything**
4. Paste into Grok and let it build + publish
5. Copy the live `*.grok.me` URL into your website builder as an iframe embed

Optional: also attach `index.html`, `robots.txt`, and `sitemap.xml` from this repo so Grok can host the pre-rendered files exactly.
